# Changelog

All notable changes to Zen Pomodoro are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-25

### Added
- Minimalist Pomodoro timer with focus and break sessions.
- Task management with per-task tracking.
- Notes panel.
- Focus music player with YouTube, SoundCloud and Spotify support, plus import/export.
- "Claude FM" default focus-music station.
- Session statistics and history.
- Multiple profiles.
- Multiple themes and changelog dialog UI.
- Offline-first storage via localStorage. No signup required.
- Open Graph image, sitemap, robots.txt and launch meta tags.

### Changed
- Removed Lovable platform tooling and references; project is now standalone.
